# Gestion-para-Restaurante-Con-Miecroservicios
Este proyecto fue desarrollado utilizando un enfoque de microservicios, donde las diferentes funciones del sistema se dividieron en servicios independientes. Entre los principales servicios que trabajamos se encuentran Fonda, Reservaciones, Taller(Clientes) y Seguridad.

El servicio de Fonda estaba orientado a la gestión de productos y ventas, utilizando elementos como productos, tipos de producto y detalles de venta. El servicio de Reservaciones se encargaba de administrar las reservaciones de los clientes. Taller se utiliza para el registro y gestión de clientes, almacenando la información necesaria de cada cliente, mientras que Seguridad se enfocaba en la autenticación y control de acceso de los usuarios.

En este proyecto utilizamos principalmente Java, Spring Boot, Maven y bases de datos MySQL, además de herramientas como Postman para probar los servicios. También trabajamos con comunicación entre servicios mediante RestTemplate.
